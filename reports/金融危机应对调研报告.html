值得警惕的结构性信号

  • 资金极度集中：2026年上半年，OpenAI和Anthropic两家公司吸走全球43%的创投资金。历史上这种集中度通常是周期尾部特征。
  • 资本开支失控式扩张：四大云巨头（微软、谷歌、亚马逊、Meta）2023年合计资本开支约2000亿美元，2025年达4130亿美元，2026年指引合计约7450亿美元。加上OpenAI主导的5000亿美元"星际之门"项目，AI基建年度总投入已突破1万亿美元——比华尔街原预测提前一年。
  • 现金流开始恶化：谷歌2026年二季度自由现金流首次转负，长期债务半年翻倍至980亿美元；亚马逊长期债务一季度暴增81%；谷歌和Meta已暂停股票回购。科技七巨头自由现金流占营收比降至7.9%，为十年最低区间。
  • 循环融资风险：英伟达向客户提供融资让客户买自己的芯片（已披露超5400亿美元此类安排，含对OpenAI高达2500亿美元的潜在担保）。国际清算银行（BIS）在2026年年报中将"循环融资"列为全球金融稳定三大风险之一。这与2000年互联网泡沫破裂前电信设备商的"供应商融资"模式高度相似。

1.2 具身智能/人形机器人：从概念到量产，中国主导

  • 融资爆炸：中国具身智能赛道2026年上半年融资约935亿元，同比暴涨5倍多；截至2026年8月初，中国机器人领域年内获投1217亿元，已超2025全年（726亿元）约67%。
  • 量产元年：2026年上半年国内人形机器人产量超4万台，全年预计超10万台。宇树科技2026年8月登陆科创板，2023–2025年营收从1.59亿增至16.99亿元，2025年人形机器人出货超5500台全球第一，毛利率60%。
  • 价格快速下探：宇树人形机器人均价从2023年59万元降至2025年16.6万元，2026年R1双臂版起售价2.69万元。
  • 风险信号：有投资人直言当前具身智能行业与2021年的新能源"颇为相似"——高估值、企业数量过多、商业化落地滞后于资本预期。高盛认为大规模部署要到2027–2029年才逐步展开，当前估值透支了未来数年增长。

1.3 半导体：AI驱动的超级周期

  • 营收创纪录：全球半导体销售额2023年5421亿→2024年6559亿（+21%）→2025年7956亿美元（+26%），2026年正逼近1万亿美元大关。
  • 格局重塑：英伟达2024年首登全球第一（767亿美元，+120%），2025年营收再增65%；SK海力士+91%、美光+71%（HBM需求暴涨）；台积电2025年营收增35.9%，净利润增46%，均创历史新高。
  • 分化明显：AI相关（逻辑、存储、先进封装）火热，而模拟、汽车、工业芯片在2025年四季度仍现营收下滑。行业繁荣高度依赖单一变量——AI资本开支的持续性。
小结：三个行业繁荣的底层是同一笔钱。云巨头的资本开支→英伟达/台积电/存储厂的营收→AI创业公司的算力采购→风投的估值锚。这条链上任何一环（电力、融资成本、AI商业化收入不及预期）断裂，都会沿产业链传导。

跨越50年的共性规律

  1. 熊市平均跌35%左右、持续约13个月；泡沫破裂型（2000年、日本）最深最久，流动性冲击型（1987、2020）最快修复。
  2. 危机剧本高度相似：估值/杠杆积累 → 导火索 → 流动性挤兑（所有资产齐跌、现金为王）→ 央行救市（降息/QE）→ 债券和黄金先涨 → 经济见底前股市先见底 → 复苏期股票涨幅最大。
  3. 避险资产排序：国债（尤其中长期，前提是危机伴随降息而非通胀）＞黄金（50年里几乎每次衰退都上涨，仅高实际利率时期例外）＞美元现金。高收益债、大宗商品、REITs不可靠。
  4. 最大的收益不是来自逃顶，而是来自危机中后期敢于分批买入。2009年3月、2020年3月买入的人，是过去两轮周期最大的赢家。
  5. 杠杆是危机中唯一必死的东西。每一轮危机死掉的都是加杠杆者，从不加杠杆的人最差结果也只是浮亏等待。

三、假设5个月后发生金融危机：分阶段行动计划

重要前提：没有人能精确预测危机时点，"5个月后"只是演习假设。方案设计原则是——即使危机不来，你也不会重大受损；如果危机真来，你有充足弹药。

阶段0：现在 → 未来5个月（备战期）

  1. 清杠杆（第一优先级）：清掉所有融资、配资、期货期权裸卖方仓位。危机中杠杆=死亡，无一例外。
  2. 建立现金堡垒：组合调整至约30–40%现金及等价物（货币基金、短期国债/逆回购）。另预留12个月以上家庭生活费，与投资资金隔离。
  3. 减仓高估值风险资产：重点减持本轮涨幅最大的AI概念、人形机器人、AI半导体链。可保留10–20%核心仓避免踏空，把"这轮赚的"落袋。
  4. 配置避险资产：黄金10–15%（实物ETF为主）；中长期国债15–20%（若担心通胀型危机则用短债替代一半）。
  5. 列好"购物清单"：现在写下危机时想买的资产及目标价位（如：宽基指数跌30%开始买；优质龙头跌40–50%开始买）。危机中人会恐惧到不敢执行，清单要提前写好。
  6. 不要做的事：不清仓到0%股票（踏空成本大）；不买高收益债"吃息"；不重仓做空。

阶段1：危机初期（崩盘后0–3个月，跌幅0%→-25%）

特征：暴跌、恐慌、所有资产齐跌（连黄金也可能短暂被抛售换现金）。

  1. 什么都不卖，也基本不买。初期最大错误是恐慌割肉在半山腰，其次是过早抄底"接飞刀"。
  2. 验证现金堡垒安全：确认货币基金/存款机构无风险，大额存款分散多家银行。
  3. 观察关键信号：信用利差是否飙升、有无大机构爆雷、央行是否表态。危机初期黄金若因流动性挤兑下跌，那是黄金的加仓点（2008年10月、2020年3月都重演过）。
  4. 指数跌到-25%左右动用第一批弹药（约现金的20%），只买指数和清单上最高质量标的。

阶段2：危机中期（约3–9个月，跌幅-25%→-40%+，恐慌顶点）

特征：标志性机构倒闭、失业上升、身边人发誓再也不碰股票、央行大幅降息/QE。

  1. 这是一生中最好的买点区间，执行购物清单。恐慌最大化的时刻往往在股市最低点附近。
  2. 分批买入，不猜底：剩余弹药分4–6批，每跌5–8%或每隔一个月投入一批。目标不是买在最低点，而是买在足够便宜的区域。
  3. 买什么：①宽基指数（不会死）；②资产负债表强壮、现金流为正的行业龙头；③被错杀的AI/半导体/机器人核心资产——买"卖铲子且赚钱的"，不买"烧钱讲故事的"。
  4. 兑现避险仓：央行开始大规模降息/QE时，逐步卖出中长期国债（此时已大涨）换入股票。黄金可多持有一段。
  5. 仍然不加杠杆。用现金买到满仓即止。

阶段3：危机后期（约9–18个月，磨底与反转）

  1. 把弹药用完，转向进攻配置：股票仓位提到70–85%，加大前期超跌的优质成长股比重。
  2. 识别真拐点信号：信用利差回落、央行从"救火"转向"托底"、经济数据环比改善。股市历史上总是领先经济数据3–6个月见底。
  3. 警惕熊市反弹陷阱：2000–02年有过多次+20%反弹后再创新低。分批策略天然免疫这个问题——继续按纪律买即可。

阶段4：危机结束后（复苏期，1–3年）

  1. 拿住不动。熊市结束后第一年标普500平均上涨40%+（2009年+68%，2020年+75%），频繁止盈会错过主升浪。
  2. 让新一轮主线浮现：每次危机后领涨的通常不是上轮泡沫的原班人马（2000年后是地产和大宗商品，2008年后是移动互联网，2020年后是AI）。
  3. 逐步恢复常态配置：牛市中期开始把股票仓位回落到长期中枢（60–70%），重建10%左右的黄金和债券底仓，为下一次危机做准备。
  4. 复盘并写下来：哪个阶段执行得好、哪里因恐惧或贪婪偏离了计划。这份记录下次危机时比任何研报都值钱。

四、新手实操问答

4.1 金融危机时，黄金什么时候买最划算？

近期（2026年8月底）金价从4697美元高点回落至4400美元附近，直接原因是美联储放鹰、9月加息预期从35%飙至66%。这是利率预期驱动的正常回调，黄金长期逻辑（央行持续购金、美国债务问题）未变。

危机中的黄金有一个反直觉规律：危机刚爆发的头几周，黄金往往跟着股票一起跌——因为所有人都缺现金，黄金流动性好反而先被卖。2008年黄金从高点跌约25%后随QE翻倍；2020年3月黄金一周跌12%，半年后创历史新高。

  • 最划算的买点＝危机初期的"流动性挤兑跌"——股市崩、黄金也莫名跟跌的时段。
  • 第二好的买点＝央行宣布大幅降息/QE时——主升浪起点，确定性更强。
  • 不划算的买点＝危机中期全民抢金时——金店排队的新闻出来时通常是阶段性高点。

操作纪律：保持固定节奏定投；金价从近期高点回撤超10%时，额外加买一份。注意当前金价处历史最高区域（两年前约2000美元），中间完全可能出现20–30%回撤，分批、留余地。

4.2 "国债"是什么？APP里的国债指数、柜台债怎么区分？

国债本质上是把钱借给国家，国家付利息，是所有资产里信用最高的。APP里的名词是买国债的三种不同"包装"：

你看到的是什么特点
储蓄国债（电子式/凭证式）在银行买的"存款式"国债，3或5年期价格不波动，绝对不亏本金，利率比定存略高；要抢额度，提前支取扣利息
柜台债银行柜台卖的可交易债券（记账式国债、地方债、政金债）价格每天波动，可随时买卖；降息时涨价，加息时跌价
国债指数/国债ETF/债券指数基金基金帮你买一篮子国债，你买基金份额性质同柜台债但门槛低、买卖方便，适合新手

关键区别：储蓄国债不涨不跌只有利息；可交易国债价格会波动——利率降它就涨，期限越长波动越大。方案中"危机时中长期国债会大涨"指的是可交易的那种（对新手最方便的是国债ETF或长久期国债指数基金）。一句话：储蓄国债≈更高息的存款，国债ETF≈降息时给你赚差价的避险工具。

4.3 "指数"是什么？

指数就是一篮子股票的平均分：沪深300＝A股最大的300家公司；标普500＝美国最大的500家公司。你买的是指数基金/ETF——基金按成分股帮你买好一整篮子。

危机方案里说"跌25%买指数"而不是买个股，原因只有一个：单个公司危机里可能破产归零，但指数不会死——公司不行了会被踢出指数、换新公司进来。指数基金是唯一可以"跌得越多越敢买、买了敢拿十年"的股票类资产，个股不是。

4.4 只有黄金、没买过股票，该怎么办？

  1. 现在就把证券账户开好——不是马上买，而是危机来时有工具可用。很多人2020年3月想抄底，卡在开户上错过整个底部。
  2. 用极小的钱练手：几百到一两千块买一点沪深300ETF，目的是亲手体会"下单、波动、浮亏"。没实际持有过的人，危机里不敢按计划买入。
  3. 主力资金保持现状：黄金继续定投，其余放货币基金/储蓄国债/国债ETF吃利息。
  4. 新手版购物清单只有一条：沪深300（或标普500）从高点跌超30%时，把现金分5批逐月买入指数基金。
  5. 不碰的东西：个股（在能看懂财报之前）、杠杆、期货期权、任何名字带"高收益"的理财。

4.5 纳指怎么看？

"纳指"一般指纳斯达克100：纳斯达克市场最大的100家非金融公司，前几大权重是英伟达、微软、苹果、谷歌、亚马逊、Meta、特斯拉。国内通过QDII基金/ETF购买，人民币直接买。

它就是这轮AI泡沫的正中心——报告第一部分列出的资本开支失控、现金流转负、循环融资的公司，加起来占纳指100超一半权重。历史体质：2000年跌78%（15年才回前高）、2008年跌54%、2022年跌33%；但2009年至今又是全球主要指数里涨幅最大的。

  • 现在（高位）：不建议建仓，最多几百块练手。当前位置大致相当于1999年的纳指。
  • 危机中期到后期：购物清单里进攻性最强的品种。纳指从高点跌45–50%即进入分批买入区域。
  • 仓位角色：沪深300/标普500是"主食"，纳指是"辣椒"——只适合股票仓位的两三成。
